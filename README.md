# Kamlin Cleaning Services – Website + Company System

هذه الحزمة تضيف لموقع كاملين:
- خدمات النظافة الأساسية.
- قسم مكافحة الحشرات والقوارض بالكامل.
- خطوات العمل.
- مزايا الشركة.
- الأسئلة الشائعة.
- مناطق الخدمة.
- نموذج حجز.
- واتساب مباشر.
- مساحة آراء العملاء.
- لوحة إدارة للطلبات والعملاء والمتابعات والضمانات والعروض والعقود.

## الملفات
- index.html: الموقع العام.
- style.css: تصميم الموقع.
- app.js: الحجز وحفظ الطلبات.
- admin.html: نظام إدارة الشركة.
- admin.css: تصميم لوحة الإدارة.
- admin.js: إدارة الطلبات والمتابعات.
- README.md: هذا الملف.

## التشغيل
افتح index.html في المتصفح.
لوحة الإدارة: admin.html

## مهم
النسخة الحالية تستخدم LocalStorage داخل المتصفح للتجربة السريعة.
هذا يعني أن الطلبات المحفوظة تظهر فقط في نفس الجهاز/المتصفح.

للعمل الحقيقي على عدة أجهزة يجب ربط النظام بقاعدة بيانات مثل Supabase أو Firebase أو Backend خاص، مع:
- تسجيل دخول حقيقي.
- صلاحيات مدير/مشرف/موظف.
- حفظ مركزي للطلبات.
- رفع صور قبل/بعد.
- إشعارات واتساب/بريد.
- نسخ احتياطي.

## مكافحة الحشرات
تمت صياغة النصوص بصورة آمنة ومهنية، بدون نسخ نصوص المنافس حرفيًا وبدون ادعاءات غير موثقة مثل:
"آمن 100%" أو "القضاء النهائي" أو "ضمان 3/5 سنوات" أو "تصريح وزارة الصحة"
إلا إذا كانت كاملين تمتلك ما يثبت هذه الادعاءات فعليًا.
